# 阿弥陀籤 (Amida-Kuji) CLI Tool

C言語で実装された、コマンドラインで動作する堅牢で効率的なあみだくじプログラムです。
メモリ管理の最適化、バッファオーバーフロー対策、および公平な抽選アルゴリズムを採用しています。

## 🚀 実行方法

### 1. コンパイル

全てのソースファイル（`.c` および `.h`）を同じディレクトリに配置し、以下のコマンドを実行してください。

```bash
make
```

### 2. プログラムの起動

コンパイル成功後、生成されたバイナリを実行します。

```bash
./amida
```

## 📖 使い方

1. **参加者の入力**:
    * 実行後、名前を一人ずつ入力して `Enter` を押します。
    * 最大20名まで入力可能です。
    * **空行（何も入力せずにEnter）** を押すと入力が終了し、くじが自動生成されます。
2. **あみだくじの確認**:
    * 画面に「名前の頭文字」「あみだの線」「当選番号」が表示されます。
3. **結果の表示**:
    * 「結果を表示しますか？ (y/n)」に対し、`y` を入力すると、当選番号順にソートされた最終結果が表示されます。

---

## ✨ 主な機能

* **公平なランダム性**: 偏りのないランダムな当選番号を生成します。
* **動的な描画**: 参加人数に応じて、あみだくじの幅と深さを自動的に調整します。
* **結果の自動ソート**: 最終結果を番号順に並べ替えて表示するため、当選者の確認が容易です。
* **堅牢な設計**:
  * `fgets` と `strncpy` によるバッファオーバーフロー対策。
  * `trace_amida` 等での不要なメモリ確保の排除による高速化。
  * 適切な `free` 処理によるメモリリークの防止。

## 📂 ファイル構成

| ファイル名 | 役割 |
| :--- | :--- |
| `header.h` | 定数定義、マクロ定義、関数プロトタイプ宣言 |
| `main.c` | メインフロー、入力ループ、メモリ解放の制御 |
| `make_amida.c` | あみだくじのグリッド構造（縦棒と横線）の生成 |
| `make_ans.c` | 重複のない当選番号のランダム生成（シャッフル） |
| `trace_amida.c` | 生成されたあみだのパスを計算・追跡するロジック |
| `print_amida.c` | あみだくじの図をターミナルに整形して出力 |
| `print_ans.c` | 結果のソート処理およびユーザーへの最終提示 |
| `malloc_str.c` | 2次元文字列配列のためのメモリ確保補助 |
| `free_str.c` | 確保したメモリの安全な一括解放 |
| `chomp.c` | 入力文字列から改行コードを安全に除去 |
