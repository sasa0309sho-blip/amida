阿弥陀籤 (Amida-Kuji) CLI ToolC言語で実装された、コマンドラインで動作する多機能な阿弥陀籤（あみだくじ）プログラムです。メモリ管理の最適化と、公平な抽選アルゴリズム（Fisher-Yates Shuffle）を採用しています。🛠 実行方法1. コンパイル全てのソースファイル（.c および .h）を同じディレクトリに配置し、以下のコマンドを実行してください。Bashgcc *.c -o amida
2. プログラムの起動コンパイル成功後、生成されたバイナリを実行します。Bash./amida
📖 使い方参加者の入力:実行後、名前を一人ずつ入力して Enter を押します。最大20名まで入力可能です。空行（何も入力せずにEnter） を押すと入力が終了し、くじが生成されます。あみだくじの確認:画面に「名前」「あみだの線」「当選番号」が表示されます。結果の表示:「結果を表示しますか？ (y/n)」に対し、y を入力すると、誰が何番に当選したかがソートされた状態で表示されます。✨ 主な機能動的な抽選生成: 参加人数に合わせて、あみだくじの幅と深さを自動調整します。公平なランダム性:高性能なシャッフルアルゴリズムにより、結果に偏りが出ないように設計されています。実行のたびに異なる形状のあみだが生成されます。結果の自動ソート: 最終結果を当選番号順に並べ替えて表示するため、確認がスムーズです。堅牢なメモリ管理: 動的メモリ確保を適切に行い、バッファオーバーフローやメモリリークを防止しています。📂 ファイル構成このプロジェクトは以下のファイルで構成されています。ファイル名役割header.hプロトタイプ宣言、マクロ定義、ライブラリのインポートmain.cプログラムのメインエントリポイント、全体のフロー制御make_amida.cあみだくじの構造（棒と横線）の生成make_ans.c重複のない当選番号のランダム生成（Fisher-Yates）trace_amida.cあみだの線を上から下まで辿るロジックの実装print_amida.cあみだくじの図をターミナルに描画print_ans.c結果のソートおよび最終表示malloc_str.c文字列配列のための動的メモリ確保補助free_str.c確保したメモリの安全な解放chomp.c入力文字列からの改行文字除去📽 動画撮影ガイド（操作手順案）デモ動画を撮影する際は、以下のステップで行うと分かりやすくなります。コンパイルシーン: ターミナルで gcc *.c -o amida を実行する様子。入力シーン: 3〜5人程度の名前（例：田中、佐藤、鈴木、高橋）をテンポよく入力。生成シーン: パッとあみだくじが表示される様子を数秒止めて見せる。結果表示: y を入力して、綺麗にソートされた結果が表示される様子を見せて終了。技術仕様言語: C11アルゴリズム: Fisher-Yates Shuffle (シャッフル), Path Tracing (追跡)メモリ: 動的確保（Dynamic Allocation）
